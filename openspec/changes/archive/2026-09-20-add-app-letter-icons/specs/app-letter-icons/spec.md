## Purpose

在应用没有可用图标字段时，用应用名生成单字母占位，避免列表和合集预览里大量相同的包装盒；已有图标地址但加载失败时仍使用包装盒。

## ADDED Requirements

### Requirement: 空图标字段展示单字母占位

当应用没有本地精选图或图标覆盖，且去掉首尾空白后的 `icon` 为空，且没有成对的可用 `iconUrl` 与 `iconPng` 时，系统 MUST 在应用图标位置展示恰好一个字符的字母图标。字符 MUST 优先取应用名中第一个可见字符（Unicode 字母、十进制数字或 CJK 表意文字），跳过空白与 `.`、`-`、`+` 等分隔符；拉丁字母 MUST 以大写展示；CJK 字符 MUST 原样展示。应用名抽不出可见字符时，MUST 改用应用 `_id` 最后一个点分段中的第一个可见字符。所有使用该图标槽位的界面 MUST 使用同一套单字符规则，MUST NOT 按卡片尺寸改为两个字符。字母图标的底色 MUST 由应用 `_id` 稳定派生，同一 `_id` 在刷新后 MUST 保持同一底色。字母图标 MUST 填满既有图标槽的方形占位，圆角与相邻真图标一致，MUST NOT 使用用户头像那种圆形。图标作为名称旁的装饰时 MUST 对辅助技术隐藏，MUST NOT 再朗读一遍应用名。

#### Scenario: 英文名取首个字母

- **WHEN** 某应用没有可用 `icon` 字段，名称为 `Visual Studio Code`
- **THEN** 图标槽展示单个大写字母 `V`，而不是包装盒图

#### Scenario: 数字与 CJK 可作为单字

- **WHEN** 某应用没有可用 `icon` 字段，名称为 `7-Zip` 或 `微信`
- **THEN** 图标槽分别展示 `7` 或 `微`

#### Scenario: 名字无效时回退到 id 分段

- **WHEN** 某应用没有可用 `icon` 字段，名称抽不出可见字符，且 `_id` 为 `Publisher.AppName`
- **THEN** 图标槽展示从最后一段取出的单个字符 `A`

#### Scenario: 连字都抽不出时仍用包装盒

- **WHEN** 某应用没有可用 `icon` 字段，且名称与 `_id` 都抽不出可见字符
- **THEN** 图标槽展示既有包装盒占位图

### Requirement: 坏图不改为字母图标

当应用已有非空 `icon` 字段、外链地址，或成对的 `iconUrl` 与 `iconPng`，系统 MUST 仍尝试加载真图。加载失败时 MUST 展示既有包装盒占位图，MUST NOT 改为字母图标。本地精选图与图标覆盖的优先级 MUST 高于字母占位。

#### Scenario: 图标地址加载失败

- **WHEN** 某应用带有非空 `icon` 或已解析的图标 URL，且图片加载失败
- **THEN** 图标槽展示包装盒占位图，而不是字母

#### Scenario: 有本地精选图时不用字母

- **WHEN** 某应用命中本地精选或图标覆盖资源
- **THEN** 图标槽展示该资源，即使目录 `icon` 字段为空

### Requirement: 合集预览保留无图标应用

当合集卡片或封面马赛克展示所含应用的图标预览时，没有 `icon` 字段的应用 MUST 仍计入预览（受既有数量上限约束），并以本能力的字母图标占位。系统 MUST NOT 仅因 `icon` 为空就把该应用从预览中丢弃。无任何可展示应用时 MUST 仍不保留空图标行。

#### Scenario: 空 icon 的应用出现在合集预览

- **WHEN** 用户查看含有至少一个无 `icon` 字段应用的合集预览
- **THEN** 该应用的字母图标出现在预览图标中，而不是被省略
